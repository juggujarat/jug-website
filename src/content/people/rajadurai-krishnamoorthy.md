Rajadurai Krishnamoorthy is a Solution Architect at OurKadai Technologies and a principal software architect with experience building highly scalable enterprise systems and e-commerce applications. Rajadurai is also a member of the Board of Studies at VIT.

At Java User Group Gujarat, Rajadurai co-presented **"Powering Machine Learning in Java with JSR 381"** in December 2024.
