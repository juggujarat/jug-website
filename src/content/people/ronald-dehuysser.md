Ronald Dehuysser is a software architect from Belgium and the creator of JobRunr, the open-source library for distributed background job processing in Java that integrates with Spring Boot, Micronaut and Quarkus.

When he's not working on open-source software, he is probably rock climbing or sipping a fine Belgian Duvel. At Java User Group Gujarat he presented **"JobRunr: Easy Distributed Job Scheduling"** in September 2026.
