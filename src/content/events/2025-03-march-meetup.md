On **Saturday, 22 March 2025**, Gujarat JUG's **March meetup** brought the community back together in person at **Staunchsys IT Services in Bodakdev, Ahmedabad**. **80 developers registered** on Luma for a morning of two very practical talks: one on the language itself, and one on how we ship it.

## Talk 1: Mastering Java's latest updates

Java now ships a new release every six months, and it's easy to fall behind. [**Priyanka Shinghala**](/people/priyanka-shinghala), Java Principal Consultant at [Staunchsys](/partners/staunchsys), took the room on a tour of the most useful features added between **Java 9 and Java 23**, including:

- **Virtual threads** (Project Loom) and what they change for blocking, thread-per-request code
- **Pattern matching** for `instanceof` and `switch`
- **Records** for concise, immutable data carriers
- The smaller quality-of-life improvements that add up when you upgrade from Java 8 or 11

## Talk 2: The art of Dockerizing Java apps

Next, [**Dhaval Gajjar**](https://www.linkedin.com/in/dhavalgajjarin/), System Architect at Staunchsys and one of Gujarat JUG's organisers, covered how to containerise Java applications properly:

- Why containers matter for Java teams, from local dev to production
- Building **lightweight images** with multi-stage builds and slim base images
- Tuning the JVM for containers, plus **performance and security** best practices
