On **Saturday, 20 September 2025**, Gujarat JUG returned to **York IE in Ambli, Ahmedabad** for a hands-on session on one of the hottest topics in AI engineering: the **Model Context Protocol (MCP)**. **152 developers registered** on Luma.

## What is MCP and why should Java developers care?

Large language models are only as useful as the context and tools they can reach. The **Model Context Protocol** is an open standard for connecting LLMs to tools, data and services in a consistent way. For Java teams, it's a way to expose existing enterprise systems to AI assistants without writing a custom integration each time.

## Building an MCP server with Spring AI

[**Milind Mehta**](/people/milind-mehta), Senior Solution Architect at [Hexaware Technologies](https://hexaware.com/), walked the room through:

- The core concepts of MCP: servers, clients, tools and resources
- How **Spring AI** makes building an MCP server feel like writing a regular Spring Boot app
- Enabling real-time interaction between LLMs and your Java services
- Designing integrations that stay **scalable and maintainable** in enterprise and AI-driven applications
