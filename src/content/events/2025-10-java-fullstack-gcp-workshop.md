On **Saturday, 11 October 2025**, Gujarat JUG went to **GIFT City, Gandhinagar**, for a three-hour hands-on workshop at [**smartSense Consulting Solutions**](/partners/smartsense). **98 people went** to meetup #14, laptops in hand, from 10:00 AM to 1:00 PM.

## The workshop

[**Falgun Bhalsod**](/people/falgun-bhalsod), DevOps Engineer at Yellow Panther and a cloud consultant across AWS, Azure and Google Cloud, showed how to take a Java fullstack app to **Google Cloud Platform** and scale it:

- Deploying Java apps on **App Engine** and **Compute Engine**
- Orchestrating workloads with **Google Kubernetes Engine (GKE)**
- Running workloads with **Cloud Functions** and **Cloud Run**
- Managing data with VM storage and **Cloud Storage**
- Strategies for scaling modern fullstack apps
