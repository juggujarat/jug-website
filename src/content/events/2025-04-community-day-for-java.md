On **Sunday, 27 April 2025**, Java User Group Gujarat hosted **Community Day for Java 2025** at **LJ University, Ahmedabad**: a full-day conference built as *Gujarat's biggest Java celebration*. It brought together **300+ Java developers, architects and students** for expert talks, networking, swag and plenty of chai.

## A headline keynote by Venkat Subramaniam

The day opened with a keynote from [**Dr. Venkat Subramaniam**](https://agiledeveloper.com/), founder of [Agile Developer, Inc.](https://agiledeveloper.com/), award-winning author and one of the most sought-after speakers in the Java world. His session, **"Using AI to create Functional Style Code"**, explored how AI assistants can help developers write cleaner, more functional Java, and where human judgement still matters.

## The sessions

- **Run Java Applications Like Never Before** by [**Vaibhav Choudhary**](/people/vaibhav-choudhary), JVM Engineer at [Salesforce](https://www.salesforce.com/), on modern JVM capabilities for faster, leaner Java in production.
- **Craft Context-Aware AI Applications using Spring Boot** by [**Jigar Shah**](/people/jigar-shah), Director of Engineering at DataOrb: a deep dive into LangChain4j and vector search for building retrieval-aware AI features in Spring Boot.
- **Chaos Engineering: A Primer with Working Demo** by [**Dhaval Shah**](/people/dhaval-shah), Principal Software Engineer at [Mastercard](https://www.mastercard.com/), showing how to break systems on purpose to make them more resilient.

## Sponsors and partners

Community Day for Java was possible thanks to our sponsors [**Codelab Technologies**](https://codelabtechnologies.com/) and [**Rezoomex**](https://rezoomex.com/) (Platinum), [**Staunchsys**](/partners/staunchsys) and [**DataOrb**](https://www.dataorb.ai/) (Gold), our venue partner [**LJ University**](https://ljku.edu.in/), and individual supporters. Fellow JUGs from **Tamil Nadu, Kerala, Bangalore and Hyderabad**, along with **Docker Ahmedabad, [Open Source Weekend](https://linktr.ee/osweekend), [CNCG Ahmedabad](https://community.cncf.io/cloud-native-ahmedabad/) and GDG Gandhinagar**, helped spread the word as community partners.
