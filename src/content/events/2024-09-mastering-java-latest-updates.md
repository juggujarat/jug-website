On **Saturday, 14 September 2024**, Java User Group Gujarat ran **meetup #1**, the session that started our monthly series. It was held online on Zoom, and **113 people joined**.

## Java 9 to 22 in one session

Java now ships a new release every six months, and it is easy to fall behind. **Mastering Java Latest Updates** was an in-depth, interactive walk through Java **9 to 22**, looking at the key features, enhancements and improvements each version introduced.

[**Vikas Rajput**](/people/vikas-rajput) presented the session, with [Bharat Ranpariya](/people/bharat-ranpariya) hosting. He picked the ten updates every Java developer should know, each with simple code examples for beginners and experienced developers alike:

1. The `var` keyword (Java 10)
2. Switch expressions (Java 12)
3. Records (Java 14)
4. Helpful NullPointerException messages (Java 14)
5. Pattern matching (Java 16)
6. Sealed classes (Java 17)
7. Virtual threads (Java 19)
8. String templates (Java 21 preview)
9. Unnamed variables (Java 22)
10. Text blocks
