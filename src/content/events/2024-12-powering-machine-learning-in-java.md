On **Saturday, 14 December 2024**, Java User Group Gujarat closed its first year with an online session on **machine learning in Java**. **111 people joined** meetup #5 on Zoom.

## The session

Speakers [**Rajadurai Krishnamoorthy**](/people/rajadurai-krishnamoorthy), Solution Architect at OurKadai Technologies, and [**Thamaraikkanni Panneerselvam**](/people/thamaraikkanni-panneerselvam), Solution Architect at lastminute.com group, took a deep dive into **JSR 381**, the Java standard API for machine learning. They covered:

- How JSR 381 supports **visual recognition** and helps Java developers use AI capabilities
- **Real-world use cases** of Java in machine learning
- A **hands-on demo** of building data-driven solutions with Java libraries

The session was designed for both experienced developers and beginners who want to keep up with AI. The full recording is below.
