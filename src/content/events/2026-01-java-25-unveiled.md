On **Saturday, 31 January 2026**, Gujarat JUG headed to Gandhinagar for meetup #16 at [**INTECH Creative Services**](/partners/intech) in Infocity. **98 people went**, one of our biggest turnouts, to see what the latest long-term-support release brings to everyday Java development. The session ran from 10:30 AM to 12:30 PM.

## The session: Java 25 Unveiled

Java 25, released as an LTS in September 2025, is a major milestone for the platform. [**Divyeshkumar Prajapati**](/people/divyeshkumar-prajapati), Assistant Consultant at TCS, walked through the improvements that make Java more expressive, scalable and cloud-ready, organised by the OpenJDK projects behind them:

- **Project Amber:** simpler everyday syntax and more flexible constructors
- **Project Loom:** virtual threads and structured concurrency for high-scale concurrency
- **Project Leyden:** faster startup times
- **Project Panama:** safe, high-performance access to native memory and APIs

The talk was aimed at developers building enterprise, cloud-native and high-throughput applications who want to know what upgrading to Java 25 gets them.
