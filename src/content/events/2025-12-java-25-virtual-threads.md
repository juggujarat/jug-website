On **Saturday, 20 December 2025**, Gujarat JUG closed the year at [**Aubergine Solutions**](/partners/aubergine) in Prahlad Nagar, Ahmedabad, with a deep dive into one of the biggest changes in modern Java: **virtual threads**. **89 people went** to meetup #15, which ran from 10:00 AM to 12:00 PM.

## The session: Java 25 Virtual Threads

[**Tanvir Dhanani**](/people/tanvir-dhanani), Senior Backend Developer at IBM India, has spent more than nine years building Java backends. He explained how virtual threads, delivered by **Project Loom**, change the way we write concurrent code:

- **How virtual threads work** under the hood, and how they differ from platform threads
- **Why they remove much of the complexity** of asynchronous and reactive programming, letting you write simple blocking code that still scales
- **Where they shine:** API-driven, database-heavy and high-throughput systems
- **How to adopt them** in existing Java codebases
