On **Saturday, 12 October 2024**, Java User Group Gujarat held **meetup #3** online on Zoom, and **113 people joined** to find out how much faster their applications could run just by moving to modern Java.

## What we covered

[**Vaibhav Choudhary**](/people/vaibhav-choudhary), JVM Engineer at Salesforce, walked through the modern Java features that make applications faster:

- **Virtual threads** for lightweight, high-scale concurrency
- **Class Data Sharing (CDS)** for faster startup and lower memory use
- **Modern garbage collectors** and what they change for latency and throughput

The session finished with **live demos comparing performance on JDK 11 and JDK 21**, showing the real-world benefits of upgrading. The full recording is below.
