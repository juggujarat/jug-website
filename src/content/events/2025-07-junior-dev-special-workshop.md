On **Saturday, 26 July 2025**, Gujarat JUG ran a special hands-on workshop for **junior Java developers** at [**7Span**](/partners/7span), Ahmedabad. **159 people went** to meetup #11, which ran from 9:30 AM to 1:00 PM.

## The workshop: Deploying Modern Java Apps

Writing an app is one thing; getting it running in the cloud is another. [**Jeemy Patel**](/people/jeemy-patel), Full Stack Java Team Lead at 7Span, and [**Vaibhav Savaliya**](/people/vaibhav-savaliya), Lead Software Engineer at 7Span, took attendees through deploying a **Spring Boot** backend and a **React** frontend to **AWS**, step by step:

- An overview of core AWS services: **EC2, S3, ECS and RDS**
- Deploying the Spring Boot and React apps to AWS
- Containerising apps with **Docker**
- Setting up **CI/CD pipelines** for automated deployments
- Basic **monitoring** for observability
- Real-world deployment tips, and a live Q&A

Attendees came with laptops set up for Java and Node.js and an AWS account, and built along with the speakers.
