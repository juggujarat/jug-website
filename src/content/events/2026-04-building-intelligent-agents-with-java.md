On **Saturday, 25 April 2026**, Gujarat JUG met at the IEEE Workspace of [**Silver Oak College of Engineering and Technology**](/partners/silver-oak) in Gota, Ahmedabad, for meetup #18. **107 people went** to learn how Java developers can build intelligent agents with tools they already know. The session ran from 10:30 AM to 12:30 PM.

## The session

[**Jigar Shah**](/people/jigar-shah), Director of Engineering at [DataOrb](/partners/dataorb), looked past the hype at what it takes to build **agentic AI** in Java. No prior AI or ML knowledge was needed. He covered:

- The shift from standard **REST APIs** to **reasoning-based architectures**
- Building **autonomous agents** that understand natural language, make decisions and call functions inside Java applications
- Turning existing Java applications into systems that can reason and interact with the world
