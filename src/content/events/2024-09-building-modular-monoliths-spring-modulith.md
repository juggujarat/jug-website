On **Sunday, 29 September 2024**, just two weeks after our first meetup, Java User Group Gujarat went online again for **Building Modular Monoliths Using Spring Modulith**. **164 people joined** on Zoom, the biggest turnout of our early online sessions.

## Why modular monoliths?

Not every system needs to start as a set of microservices. A **modular monolith** keeps the simplicity of a single deployable application, while splitting the code into well-defined modules with clear boundaries. **Spring Modulith** is the Spring project that helps you build, verify and document that structure in a Spring Boot application.

Our speaker was [**Siva Reddy**](/people/siva-reddy), Developer Advocate at JetBrains, known to many Java developers as **SivaLabs**. He showed how Spring Modulith brings structure to a Spring Boot monolith. The full recording is below.
